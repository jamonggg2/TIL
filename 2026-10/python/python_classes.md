# 클래스
- 클래스명 첫글자대문자 + 카멜케이스
- 인스턴스 : 클래스를 생성한것
- ==로 값을 비교할수있고, is로 같은 인스턴스인지 비교할수있다
- 매직메서드 : __이름__ 의 형태로 이미 지정된 기능이 있음
- 클래스변수 : 클래스안에서 변수명=값 으로 선언되며, 모든 인스턴스가 같이씀
    - 사용시에는 클래스명.변수명 으로 사용함
    - 인스턴스.클래스변수 로 값을 새로지정하면 클래스변수의 값이 아닌 같은 이름을가진 인스턴스변수가 생성됨
    - 클래스.클래스변수 로 값을 새로지정하면 본 클래스변수값이 변경됨
- self : 만들어지는 그 인스턴스
    - self.속성명 = 매개변수 : 이 형태로 속성에 값넣기
    - 호출시에는 부르지않아도됨


## 메서드 
- self를 인수로 받아야한다
- `def 메서드명 (self, 매개변수들): 실행할코드 (self.속성 형태로 사용하여)`
- 인스턴스.메서드명(인수) 로  호출한다
- 메서드 안에서도 self.다른메서드명() 으로 호출한다

### 생성자
__init__
- 인스턴스 생성순간 자동실행되는 메서드
- 생성자가 인수를 받는경우 인스턴트생성때 값을 넣어주지 않으면 오류가발생하며
    - 기본값 설정을 해놓는경우 오케이 (인수 = 기본값 형태로)

### __str__
- print(인스턴스명) 할때 출력한 문자열을 지정하는 메서드
- 없는경우 메모리주소가 프린트됨
- return 보여줄내용 형태로 작성

## 메서드 인수로 다른 객체 받을 수 있음
- 다른인스턴스(객체)를 인수로 받을 수 있다
- ex `def __init__(self, 다른인스턴스): self.속성 = 다른인스턴트`
- `인스턴스명.다른인스넣은변수명.다른인스의변수명`  이렇게도 값꺼내기 가능

## 클래스메서드
- `@classmethod` 로 메서드위에 담
- 클래스를 리턴하는 메서드
- cls(클래스)를 첫번째 인자로 두어야함
- `return cls(이것, 저것) `
- 받는 인수형태가 달라도 처리해서 클래스생성을 할수있게 한다던가 할떄 사용가능
- 인스턴스생성떄 `클래스.클래스메서드(값값)` 하고 생성

## 데이터클래스
- 값을 넣는게 주된 클래스에서 사용
- `from dataclasses import dataclass` 필요하며 없으면 오류발생
- `@dataclass` 붙여서 적용
- 속성명과 타입힌트(및 기본값)을 적으며, 이 순서와 인자순서로 자동매핑된다 (init불필요)
- 기본값이 없는것부터 먼저 작성하며, 있는것을 후에 작성한다. (자동매핑으로인한 오류발생위험때문에 오류발생가능)
```
from dataclasses import dataclass

@dataclass
class 클래스이름:
    속성: 종류
    속성: 종류 = 기본값

# 예시
    text : str
    number : int = 0
```

## 상속
- `class 자식명(부모명) :`
- 자식에서 같은이름의 메서드를 만들지않았으면, 부모메서드 내용을 그대로쓸수있음
    - 자식꺼 같이름으로쓰이면 그자식꺼는 그내용으로
    - 실행시 자식의것이쓰인게아니라 부모께쓰인거임
- `super().__init__(변수)` : 부모의 init을 불러서 그 기능을 사용가능
- `isinstance(값, 클래스)` : 값이 그클래스나, 그의자식인지 bool로 리턴

## 추상화
- `@abstractmethod`
- 추상클래스의 추상메서드는 부모에서 선언만해놓고, 자식들의경우 무조건 추상메서드의 구현을 해야함
- import와 부모클래스에 부모로 ABC 필요
from abc import ABC, abstractmethod
```
class 부모(ABC):
    @abstractmethod
    def 메서드이름(self):
        pass

class 자식(부모):
    def 메서드이름(self):
        실제 코드
```
