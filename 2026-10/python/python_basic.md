## 타입
- `type(확인필요한것)` 으로 해당변수나 값의 타입확인가능
- int:정수, float:실수
    실수가 정수를 포함하는 더 넓은 타입이다. 
    정수와 실수를 더하거나뺴면 실수타입이된다
- str:문자열
- bool:True False 대문자로시작하는 참거짓값

## f-string
- 변수값을 사용하여 동적으로 문자열 구성할떄
`f'{변수1}은 {변수2}입니다'`
- 이전버전엔 이렇게 처리되어있을수도
    - `"{}은 {}입니다".format(변수1,변수2)`
    - `"%s은 %d입니다"%(변수1,변수2)`

## if 조건문
- if 조건: 
    - 끝에 :콜론 꼭붙일것
    - 조건문은 괄호가아니라 들여쓰기로 묶음. 같은 수준의 들여쓰기가 되어있으면 같은블럭
- elif, else
- pass
- 조건표현식 : 짧은 if else는 한줄로가능
    참일때값 if 조건 else 거짓일떄값
    `print('True') if test == test else print('False')`

- 0 , "" 는 False로치고 나머지는 True로친다

## and or not
- and : &&
- or : ||
- not : ! 참거짓뒤집기 

### 단축평가
- or, and 조건중에 앞조건만보고 결과가 정해지면 뒷조건을 보지않고, 마지막본값을 리턴
- or경우 앞이 거짓이면 뒤를본다, 앞이 참이면 거기서 끝난다
- and경우 앞이거짓이면 거기서 끝이다, 앞이참이어도 뒤를 본다 

### 연쇄비교
- 수학처럼 한줄쓰기가능.
```
20 >= age and age < 30
20 >=  age < 30 
```
위의 두 줄은 같음

## 반복문

### range()
- 범위를 나타냄
- range(5) : range(0,5) 0부터4까지(5전에)
- range(1,6) : 1부터 5까지(6전에)
- range(0,10,2) : 0부터 2씩 10전까지(8)

### for
- `for ... in ...:`
- for i in range(5): <- 0,1,2,3,4 가 i에 차례로 들어갑니다
- in 뒤에는  문자열도 들어갈수있고(이터러블한..), 문자열 차례로 값에 들어가서 돕니다

### while
- 조건이 True인 동안 계속반복
- `while 조건 :`
- 혹시 무한반복걸리면 주피터 노트북인경우 Kernel -> Interrupt Kernel

### break 반복종료

### continue 
- 이번차례의 남은거 건너뛰고 다음차례로 간다(반복의 다음턴을 의미)


## 함수

- 순서 번호와 값을 함께꺼낸다 (0부터시작)
- enumerate("abc") -> (0,"a")(1,"b"),(2,"c")
