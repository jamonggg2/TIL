# SQL Transcation
- DB안정성 보장을 위해 여러작업을 단위로 묶어 처리하는 논리작업세트
    - 여러 데이터베이스에 묶여서 작업이 일어나야 하는경우등, 중간에 일부만 처리가 되거나 되지않으면 안되기때문에 사용

## 사용법
`BEGIN` -> 쿼리 -> 결과확인 -> `COMMIT` or `ROLLBACK`
- BEGIN : 트랜젝션 시작 명령어
- COMMIT : 쿼리가 적용되며, 트랜젝션 사용하지않고 작업하는것과 마찬가지로 상태종료
- ROLLBACK : BEGIN 이후 작성된 모든 쿼리 적용되지 않으며 그 전상태로 돌아간다

## 주의사항
- commit을 한 이후에는 rollback불가하다
- SQL 명령어이기때문에 모든 명령의 끝에는 `;` 가 포함되어야한다
- 쿼리로 인한 오류가 발생하면 rollback을 해야하며, commit을 시도해도 rollback으로 강제된다
- commit전까지는 DB에 실제로 반영되지 않으나 해당 데이터들은 holding중이다
    : 트렌젝션으로 잡혀있는 것을 다른곳에서 접근하여 조작하려고 하는경우, 이로인해 로딩이 걸리며 트렌젝션완결후에 처리된다

## 낙/비관적 락
- 비관적 락 : 동시수정이 많을것으로 예상하여 트랜젝션을 통해 hold하여 락걺
- 낙관적 락 : 동시수정이 거의 없을것으로 예상하여 락을 걸리지않고 오류처리로 빠지게 함
