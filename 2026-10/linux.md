## 경로
- `~` : 내 홈 폴더
- `.` : 지금 있는 폴더
- `..` : 한 칸 위 폴더
- 나머지 : 상대경로 

# 명령어
- `pwd` : print working diractory 내가 지금 작업중인 공간위치 띄우는 명령어
- `ls` : 현재 있는 폴더 안에 있는거 보여줌
- `ls 폴더명` : 특정폴더 안에 있는거 보여줌
- `ls -l` : 자세히보기
- `ls -a` : 숨김파일까지보기기(.으로시작하는파일이나 폴더)
- `ls -la`: 자세히보기+숨김파일까지

- `cd` : change directory 폴더변경(목적지를 뒤에 꼭)
```
cd .. (하나위 폴더로)
cd ~ (홈폴더로)
cd 폴더명
cd 폴더명/폴더안의폴더명 
cd 폴더명앞글자+tab (해당문자로 시작하는 파일폴더 or 하나밖에없으면 자동완성)
```

- `mkdir` : make direactory (새폴더명을 뒤에 꼭)
```
mkdir 폴더명 (폴더명 이라는 폴더생성)
mkdir -p 폴더명/폴더명2 (중간의 부모폴더까지 한번에 생성 하는 옵션-p)
```

- `touch` : 파일생성 (생성명을 뒤에 꼭)
```
touch 파일명.확장자
touch test.txt (test.txt 이름의 빈파일 생성)
```

- `echo` : 출력해줌
```
echo '안녕하세요' 
```

- `>`, `>>` : 왼쪽에 결과를 > 오른쪽에 쓰기
- `>` : **새로쓰기**, **덮어쓰기**
- `>>` : 기존에다 추가하기 
```
echo 'hi' > test.txt (꼭 txt가 아니어도 확장자 무관가능_기능은 다른이야기_어차피다코드인거잔아)
ls > text.txt (콘솔 출력되는거면 다 넣을수있다는 겁니다)
```

- `clear`, 컨트롤+L : 터미널 지우기

- 파일내용보기 (해당 명령어 뒤에 파일명입력필)
    - `cat` : 전체출력
    - `head` : 위10줄
        - `head -2` : 위의 2줄(숫자 변경가능 옵션)
    - `tail` : 아래10줄
        - `tail -3` : 아래 3줄(변경가능 옵션)
    - `less` : 페이지 열어서 전체보기 (Q로 나가기)


- `cp` : copy
- `mv` : move, rename
- `rm` : remove (파일삭제)
- `rm -r` : 폴더삭제
```
cp 파일명 폴더명 (해당폴더로 파일을 복사)

mv 파일명 폴더명 (해당폴더로 파일을 이동)
mv 파일명 새파일명 (파일을 새파일명으로 변경_같은폴더)

rm 파일명 (휴지통없는 파일 완전삭제)
rm -r 폴더명 (폴더삭제)
```

- `grep` : 해당 단어가 잇는 줄 출력
```
grep 찾는문자 파일명
grep hi linux.md

ls -l | grep 찾는문자 (ls -1 폴더안파일자세히보기 에서 찾는문자 있는 파일에대한거만 보기)
ls -l | grep linux 
```

- `which` : 이 명령어가 어디있는지 출력
```
which node (node명령어 위치)
```

- `--help` :명령어(거의대부분) 사용법이 출력됨
```
cat --help (cat명령어 사용법 출력)
```

- `find` : 폴더안까지 뒤져서 해당이름 파일(및 위치) 찾기
```
find 시작위치폴더명 -name "이름"
find 시작위치폴더명 -name "패턴"
find . -name "*.txt"
```

- `wc`: 글자수 세기
    - `wc -l` : 줄수 세기
```
cat 파일명 | wc -l ->파일의 줄세기
cat *.확장자 | wc -l -> 폴더안의 해당확장자가진 모든파일의 줄수합세기
```

- `diff` : 옛파일 새파일의 차이점만 보기
```
diff 파일1 파일2 ->파일1과 파일2에서 파일1에만있는줄"<"표시 파일2에만있는줄">"표시로 뽑아준다
```
