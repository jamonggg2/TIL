# claude_code

## 설치 및 프로젝트생성
1. 터미널에서 claude code 설치
2. 프로젝트폴더 안으로 이동하여 터미널에서 `claude` 명령어로 실행
    - 최초실행시 로그인연동필요

## /기선언 명령어
/명령어 형태의 사전에 선언되어있는 명령어를 사용할 수 있음
`/model `: 모델설정
`/usage` : 사용량확인
`/context` : 현재 사용중인 컨텍스트 윈도우(토큰용량)을 시각적으로 보여줌
`/permisstion` : ai의 권한내용 설정확인

## 컨텍스트
`~/.claude/CLAUDE.md `
- 해당 파일을 생성, 설정하여 모든 프로젝트에 해당되는 컨텍스트설정이 가능하다
- .claude 폴더부터 생성하여야한다
- md파일에 자연어와 markdown문법을 사용하여 컨텍스트를 작성한다

`프로젝트폴더/.claude/CLAUDE.md`
- 프로젝트 폴더 내에 해당 파일(및경로)를 생성하여 해당 프로젝트에만 적용되는 컨텍스트를 설정한다

## 코드를 이용한 settings
`~/.claude/settings.json `
`프로젝트폴더/.claude/settings.json`
- json을 사용하여 코드로 규칙을 설정할 수 있다
- md파일에서 자연어 설정이 희석될 여지가 있으므로 코드레벨로 설정이 필요한 것은 이곳에도 작성한다
- 자주 사용할만한 설정들
    1. permissions : mode설정중 디폴트모드, 사용자승인없이 ai자동실행허용과 비허용영역등을 설정한다
        - plan mode : 사용자에게 계획을 확인받으며 진행하는모드
        - deny : 비허용(env파일 읽고 쓰기 등)
